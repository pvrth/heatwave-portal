JavaScript Programs

Six standalone programs covering variables, operators, conditions, objects, arrays and regular expressions. Each one runs in the browser and shows its output on the page, in an alert or in the console.

1. Temperature analysis

Compares the current temperature with the heatwave threshold and prints the status using alert(), document.write() and console.log().

Open heatwave_analysis.html

2. Risk and early warning

Recommends a warning level from temperature, humidity and forecast values using if, else if and else.

Open heatwave_warning.html

3. Climate object

An object literal that stores climate readings and exposes methods for display, difference, risk, early warning and alert updates.

Open climate_object.html

4. Array analysis

Analyses ten temperature readings with loops: minimum, maximum, average and threshold counts.

Open temperature_analysis.html

5. Registration validation

Validates user name, mobile, email, location, user ID and PIN with regular expressions and field-level errors.

Open climate_validation.html

6. Registration form

A full registration form with ten fields, highlighting, future-date checks and a success message after validation.

Open climate_registration.html
